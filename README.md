# maya-kin-engine · 玛雅历法引擎

> 双体系玛雅历计算引擎：**A 现代十三月亮历（Dreamspell）** + **B 传统玛雅圣历（Tzolk'in / Cholq'ij，GMT 584283 学术换算）**。
> 零依赖单文件、23 条固化测试向量上电自检，与小红书《玛雅天赋图腾》小工具**生产环境同源同码**。

只输入生日（无需出生时间与地点），即可得到两套体系各自完整的解读数据。AI 或人类都不要心算玛雅历——2 月 29 日跳跃与模 260 环会让心算必错，交给引擎。

## 30 秒上手

```bash
node maya_engine.js 1990-05-15                     # 双体系完整档案
node maya_engine.js trad 1990-05-15                # 传统玛雅命盘（nawal+数字+旬+Katun）
node maya_engine.js match 1990-05-15 1993-08-20    # 双人合盘
node maya_engine.js year 1990-05-15                # 未来 5 年个人流年
node maya_engine.js guide13                        # 未来 13 天能量指南（可传偏移天数）
node maya_engine.js today                          # 今日 Kin + 今日 nawal
node maya_engine.js selftest                       # 23 条测试向量自检
npm test                                           # 等效：日期向量 + 自检 + 新功能结构校验
```

全部输出 JSON，适合 AI 直接调用组织语言（这正是小红书 Skill 版的用法）。完整真实输出见 [docs/examples.md](docs/examples.md)。

## 两套体系，一个引擎

| | A · 13月亮历（Dreamspell） | B · 传统玛雅历（Tzolk'in） |
| --- | --- | --- |
| 来源 | 1987 年 José Argüelles 现代创编 | 超过两千年活传统，危地马拉日守人（Ajq'ij）沿用至今 |
| 换算 | 体系自设规则（每年 7/26 换年） | GMT 584283 学术常数（与博物馆展签、论文一致） |
| 闰日 | 2 月 29 日不占 Kin（0.0 Hunab Ku） | 照常推进，每四年多走一步 |
| 语言 | 银河签名 Kin、五大印记、波符、城堡 | nawal 出生日名、13 数字、出生旬、Katun 时代 |

同一个生日在两套体系下结果不同属**正常**——它们是两条平行的河，不是新旧两版。引擎如实分列、互不冒充，并给出错位量与彩蛋解读（如 1960–1964 罕见同位窗口、2 月 29 日生日的专属文案）。

## 它能算什么

**A 体系（13月亮历）**
- 银河签名 Kin 1–260：图腾 × 调性，附四色家族解读
- 五大天赋印记（银河神谕盘）：主印记 + 引导（成长方向）/ 支持（天赋盟友）/ 挑战（扩张张力）/ 隐藏推动（深层礼物），四个位置全部原生计算
- 波符（20 段 × 13 天，含位置）、五城堡、地球家族、和声单元、核心日
- 个人流年：每过一个生日印记前进 105，未来 5 年逐年主题

**B 体系（传统玛雅）**
- 长纪历（Long Count）与太阳历（Haab'）
- 出生日名 nawal：20 个完整档案（尤卡坦名/高地 K'iche' 名/力量面/阴影面/择日传统/传统记载）
- 13 数字修正（"日名是什么力量，数字是什么档位"的传统语法）
- 出生旬 trecena：20 旬各自的主题与你在旬中的位置
- Katun 时代之轮：13 段约 19.7 年的时代窗口（据《Chilam Balam》Roys 英译本概括演绎）

**跨体系与场景工具**
- `dual`：双历对照（两套读数 + 错位量 + 特殊年代彩蛋）
- `guide13`：未来 13 天逐日能量（双体系并排 + 波符/旬位置）
- `match`：双人合盘（色彩关系/五印记角色命中/调性节奏距离）
- 名人同 Kin：484 位公众人物按公开生日**实时计算**（不是人工标注，永不与算法不一致；生日存疑或形象有争议者不收）

## 为什么可信

- **23 条固化测试向量**（lawoftime.org / 13moon.com / starroot 多源交叉验证），每次运行先自检
- 修复了多数在线计算器都会算错的**闰日边界**：2 月 29 日不占 Kin；1916 年前历史日期同样正确——爱因斯坦 1879-03-14 = Kin 260（很多计算器给出错值）
- 官方锚点验证：2013-07-26 = Kin 164、2026-07-26 = Kin 229
- 双体系不互相冒充：2012-12-21 古典历为 4 Ajaw 3 K'ank'in、Dreamspell 为 Kin 207 蓝水晶之手——两个都对，因为它们是两套历法
- 传统体系与危地马拉日守人、博物馆、学术论文同一套换算（GMT 584283）

## API

```js
const { profileOfDate, matchOf, tradOfDate, dualOf, guide13, engine, celebs } = require('./maya_engine');

profileOfDate(1990, 5, 15);    // 完整档案（含 trad 传统命盘 + dual 双体系对照 + 同 Kin 名人）
tradOfDate(1990, 5, 15);       // 传统玛雅命盘
matchOf('1990-05-15', '1993-08-20');  // 合盘（色彩关系 / 五印记角色 / 调性节奏）
guide13(0);                    // 从今天起未来 13 天（可传偏移天数）
engine.kinOfDate(2026, 7, 26); // 229
```
